# Vitalsy AI — Marketing Website

Premium SaaS landing site for **Vitalsy AI**, an AI-powered health and wellness assistant mobile application.

## Tech Stack

- [Next.js 15](https://nextjs.org/) (App Router, TypeScript)
- [Tailwind CSS](https://tailwindcss.com/) with dark mode support
- [Framer Motion](https://www.framer.com/motion/) animations and micro-interactions
- [Lucide](https://lucide.dev/) icons
- [next-themes](https://github.com/pacocoursey/next-themes) for light/dark theme switching

## Features

- Hero with CSS-built 3D phone mockup and floating glassmorphism metric cards
- Features grid, How It Works, Benefits with animated trend panel
- Interactive app screenshots carousel (auto-advancing, keyboard accessible)
- Animated statistics counters, testimonials, SaaS pricing cards, FAQ accordion
- Final download CTA with App Store / Google Play badges
- SEO: metadata, Open Graph, sitemap.xml, robots.txt
- WCAG-minded: semantic landmarks, skip link, focus styles, reduced-motion support
- Fully responsive, mobile-first

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```

## Deployment

Deployed on [Vercel](https://vercel.com/). Push to `main` to trigger a production deployment.
